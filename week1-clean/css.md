# CSS

## CSS는 웹페이지를 꾸미는 언어이다.

## CSS 기본 문법

선택자 {
속성: 값;
}

### 예시

p {
color: red;
}

## Selector

### CSS에서 스타일을 적용할 HTML 요소를 선택하는 방법이다.

- 태그 선택자 :`<p>`, `<div>`
- 클래스 선택자 :`<.class>`
- 아이디 선택자 :`<#id>`

## Box Model

- `<margin></margin>`: 요소 바깥쪽 여백이다
- `<padding></padding>`: 요소 안쪽 여백이다
- `<border></border>`: 요소의 테두리를 만드는 속성이다
