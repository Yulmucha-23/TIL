# Git 기본 개념

### Git은 파일의 변경사항을 기록하고 관리하는 버전 관리 시스템이다

## 특징

- 파일의 수정 내역을 저장할 수 있다
- 이전 버전으로 되돌릴 수 있다
- 협업할 때 변경 내용을 쉽게 관리할 수 있다

## 기본 명령어

### 파일 추가

- git add
- 변경된 파일을 저장할 준비 단계

### 커밋

- git commit
- 변경 내용을 기록하는 단계

### 푸시

- push origin main
- 로컬 저장소의 내용을 원격 저장소에 업로드

### 풀

- git pull origin main
- 원격 저장소의 최신 내용을 가져오기
