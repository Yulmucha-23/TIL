# HTML

## HTML은 웹 페이지의 구조를 만드는 언어이다.

## HTML 기본 구조

- `<!DOCTYPE html>` : HTML5 문서라는 것을 브라우저에게 알려준다.
- `<html></html>` /html : HTML 문서의 시작과 끝을 나타낸다.
- `<head></head>` : 웹페이지의 정보가 들어가는 부분
- `<title></title>` /title : 브라우저 탭에 표시되는 웹페이지 제목
- `<body></body>` /body : 실제 사용자에게 보여지는 웹페이지 내용이 들어가는 영역

## 주요 태그

- `<div></div>` /div : 영역을 나누는 태그
- `<span></span>` /span : 텍스트 일부를 묶는 태그
- `<p></p>` : 문단을 만드는 태그
- `<a></a>` : 다른 페이지로 이동하는 링크 태그
- `<img>` : 이미지를 표시하는 태그
- `<form></form>` : 사용자 입력을 받는 폼
- `<input>` : 입력창을 만드는 태그
- `<button></button>` : 버튼을 만드는 태그

## 시맨틱 태그

- `<header></header>` : 페이지 상단 영역
- `<main></main>`: 페이지의 주요 내용
- `<section></section>` : 내용의 구역을 나눌 때 사용
- `<footer></footer>` : 페이지 하단 영역
