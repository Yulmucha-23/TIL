# JavaScript 기본 문법

## 함수 (Function)

### 1. 함수란?

- 특정 목적의 작업을 수행하기 위해 독립적으로 설계된 코드의 집합이다

- 역할: 반복되는 코드를 하나로 묶어 필요할 때마다 호출하여 재사용할 수 있게 한다

- 구조: 입력(매개변수) -> 처리(본문) -> 출력(반환값)의 과정을 거칩니다.

### 2. 함수 선언

- 가장 전통적인 방식의 함수 정의 방법이다

- 특징: function 키워드와 함수 이름을 사용하여 정의합니다 코드 어디서든 호출할 수 있는 유연함이 있습니다

### 3. 화살표 함수 (Arrow Function)

- ES6에서 도입된 더 간결한 함수 작성 방식이다

- 특징: function 키워드 대신 => (화살표)를 사용합니다. 코드가 한 줄일 경우 return과 중괄호를 생략할 수 있어 매우 간결합니다

- 용도: 주로 짧은 콜백 함수나 현대적인 자바스크립트 프로젝트에서 표준처럼 널리 사용됩니다

### 4. 매개변수(Parameter)와 반환값(Return)

- 매개변수: 함수를 실행할 때 외부에서 전달받는 재료 이다

- 반환값: 함수가 처리를 끝내고 자신을 호출한 곳으로 돌려주는 결과물이다
