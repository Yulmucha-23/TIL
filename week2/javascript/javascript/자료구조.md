# JavaScript 기본 문법

## 자료구조 (Data Structure)

### 1. 배열 (Array) 이란?

- 연관된 데이터를 하나로 묶어서 관리하는 순서가 있는 목록이다

- 구조: 대괄호 []를 사용하여 선언하며, 각 요소는 쉼표(,)로 구분한다

#### 특징 :

- 인덱스(Index): 데이터마다 번호(0부터 시작)가 붙어 있어 원하는 위치의 값을 빠르게 찾을 수 있다

- 용도: 비슷한 성격의 데이터를 한꺼번에 처리할 때 사용한다

### 2. 객체 (Object) 이란?

- 이름(Key)과 값(Value)이 한 쌍으로 이루어진 데이터 집합이다

- 구조: 중괄호 {}를 사용하여 선언하며, key: value 형태로 데이터를 저장한다

#### 특징:

- 속성(Property): 데이터에 이름을 붙여서 저장하므로, 해당 데이터가 무엇을 의미하는지 명확하게 알 수 있다

- 용도: 하나의 대상에 대한 여러 정보를 묶어서 관리할 때 사용한다
