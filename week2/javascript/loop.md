# JavaScript 기본 문법

## 반복문 (Loop)

### 1. for 문이란?

- 정해진 횟수만큼 코드를 반복 실행할 때 사용하는 가장 대표적인 반복문이다

- 역할: 어디서부터, 어디까지, 몇 번씩 반복할지 한 줄에 정의하여 정확한 횟수를 제어합니다

- 구조: for (초기값; 조건식; 증감식) 형태로 구성됩니다

- 용도: 배열의 처음부터 끝까지 훑거나, 1부터 100까지 숫자를 더하는 등 반복 횟수가 명확할 때 사용합니다.

### 2. while 문이란?

- 주어진 조건이 참(true)인 동안 코드를 계속해서 반복 실행하는 제어문입니다

- 역할: 반복 횟수가 정해져 있지 않아도, 특정 조건이 충족되는 동안에는 무한히 반복할 수 있다

- 주의사항: 조건이 계속 참이면 무한 루프에 빠질 수 있으므로, 반드시 반복을 멈출 장치가 안에 있어야 한다

- 용도: "사용자가 정답을 맞힐 때까지", "파일을 다 읽을 때까지"처럼 특정 상황이 끝날 때까지 반복해야 할 때 사용합니다.

---

### forEach 란?

- forEach() 함수는
  배열을 순회해서 각 요소를 콜백 함수로 처리하기 위한 함수입니다.
  배열의 각 요소에 대해 주어진 콜백 함수를 적용해서 순서대로 한 번씩 실행합니다.
- 콜백 함수(Callback function)는 다른 함수에 매개변수(인자)로 전달되어, 특정 작업이나 이벤트가 완료된 후 외부 함수에 의해 '나중에 호출(Call back)'되는 함수이다

---

### map()함수 이란?

- map() 함수는 배열의 모든 요소에 콜백 함수를 적용하여 그 결과값들로 구성된 새로운 배열을 반환하는 고차함수입니다
