# JavaScript 기본 문법

- ## 변수 (Variable)

### 1. let 이란?

- 재할당이 가능한 변수를 선언할 때 사용하는 키워드입니다

- 특징: 변수를 만든 후에도 상황에 따라 안에 담긴 값을 바꿀 수 있다 하지만 똑같은 이름으로 변수를 다시 만드는 것은 불가능하다

- 용도: 프로그램 실행 중 값이 계속 변해야 하는 경우에 사용한다

### 2. const 이란?

- 재할당이 불가능한 상수를 선언할 때 사용하는 키워드입니다

- 특징: 한 번 값을 담으면 절대로 바꿀 수 없으며, 선언과 동시에 반드시 값을 넣어야 한다 재선언이 불가능하다

- 용도: 값이 변하지 않아야 하는 보안상의 이유나, 실수로 값을 바꾸는 것을 방지하기 위해 사용합니다
