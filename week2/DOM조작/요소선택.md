# DOM 조작

## DOM (Document Object Model) 이란?

- #### 웹 페이지(HTML)를 자바스크립트가 이해할 수 있는 객체 형태로 나타낸 모델이다

- 역할: 자바스크립트를 사용하여 HTML 요소의 스타일을 바꾸거나, 내용을 수정하고, 새로운 요소를 만드는 등 동적인 웹 페이지를 구현하게 한다

---

## 요소 선택 (Element Selection)

### 1.document.querySelector() 이란?

- CSS 선택자를 사용하여 조건에 맞는 첫 번째 요소 하나만 선택하는 메서드이다

- 특징: ID(#), 클래스(.), 태그명 등 모든 CSS 선택자를 사용할 수 있어 매우 범용적입니다

- 용도: 특정 아이디를 가진 버튼이나, 페이지 내에서 단 하나만 존재하는 요소를 제어할 때 사용한다

### 2.document.querySelectorAll() 이란?

- CSS 선택자와 일치하는 모든 요소를 선택하여 리스트(NodeList) 형태로 가져오는 메서드이다

- 특징: 일치하는 요소가 여러 개일 때 유용하며, forEach 같은 반복문을 사용하여 선택된 모든 요소를 한꺼번에 조작할 수 있습니다

- 용도: 여러 개의 리스트 아이템(li)이나 동일한 클래스를 가진 여러 버튼에 공통적인 기능을 넣을 때 사용합니다

---

#### `getElementById('아이디')`

정해진 이름(ID)으로 바로 가는 직통 노선입니다.

특징: 속도가 가장 빠름. 딱 하나만 집을 때 씀.

---

#### `getElementsByClassName('클래스')`

요소가 추가/삭제되면 알아서 리스트를 업데이트합니다

특징: 클래스 이름으로 뭉텅이로 가져옴. 실시간 반영됨

---

##### 클래스명이 없어도 주변 요소를 이용해서 찾아가는 방법

- `closest('.클래스')`

특징: 내 위로 올라가면서 가장 가까운 조상을 찾음.

- `parentElement`

특징: 바로 위 부모를 딱 집음.
