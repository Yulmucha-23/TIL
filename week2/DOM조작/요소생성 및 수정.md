# DOM 조작

## 요소 생성 및 수정 (Manipulation)

### 1.document.createElement() 이란?

- #### HTML에 실제로 존재하지 않는 새로운 태그(요소)를 메모리상에 생성하는 메서드이다

- 역할: 버튼, 리스트, 이미지 등 어떤 태그든 자바스크립트로 직접 만들어낼 수 있다

### 2. appendChild() 이란?

- #### 생성하거나 선택한 요소를 특정 부모 요소의 자식으로 추가하는 메서드이다

- 역할: createElement로 만든 요소를 실제 웹 화면(DOM 트리)에 붙여서 보이게 만든다 보통 부모 요소의 가장 마지막 자식으로 들어갑니다

### 3. innerHTML 이란?

- #### 요소 내부의 HTML 마크업 자체를 가져오거나 설정하는 속성이다

- 특징: 태그(`<strong>`,` <span>` 등)를 포함한 문자열을 넣으면 브라우저가 이를 해석해 실제 태그로 렌더링한다

- 주의: 외부 사용자의 입력을 그대로 넣을 경우 보안 취약점(XSS 공격)이 생길 수 있어 주의가 필요합니다

### 4. textContent 이란?

- #### 요소 안에 있는 순수한 텍스트 내용만 가져오거나 설정하는 속성이다

- 특징: HTML 태그를 넣어도 해석하지 않고 문자 그대로 출력한다 innerHTML보다 성능이 빠르고 보안상 안전하여 단순 글자 수정 시 가장 권장됩니다
