# Flex & Grid 레이아웃

## Flex(Flex Box/ Flexible Box) 란?

- 행 또는 열을 기준으로 요소를 배치하는 1차원 레이아웃 모델이다

## 주요 속성:

1. ### display: flex :

- 부모 요소를 Flex 컨테이너로 설정하여 자식 요소들을 유연하게 배치한다

2. ### justify-content :

- 메인 축을 기준으로 자식 요소들 사이의 간격과 정렬을 조절한다

3. ### align-items :

- 교차 축을 기준으로 자식 요소들의 수직 정렬을 결정한다

---

## Grid 란?

행과 열을 동시에 제어하는 2차원 레이아웃 시스템이다

## 주요 속성:

1. ### display: grid :

- 부모 요소를 Grid 컨테이너로 설정하여 바둑판 모양의 설계를 가능하게 한다

2. ### grid-template-columns :

- 열(세로줄)의 개수와 너비를 설정합니다

3. ### grid-template-rows :

- 행(가로줄)의 개수와 높이를 설정합니다

## Flex vs Grid 차이점

### Flex (1차원)

- 기준: 한 번에 하나의 축(가로 또는 세로)만 다룹니다

- 특징: 요소의 크기가 불분명하거나 콘텐츠의 양에 따라 유동적으로 배치해야 할 때 유리하다

## Grid (2차원)

- 기준: 가로(행)와 세로(열)를 동시에 다룹니다

- 특징: 페이지 전체의 큰 구조를 잡거나, 요소들을 바둑판 형태로 정교하게 배치해야 할 때 유리하다
