# Flex & Grid 레이아웃

## Flex(Flex Box/ Flexible Box) 란?

- 행 또는 열을 기준으로 요소를 배치하는 1차원 레이아웃 모델이다

## 주요 속성:

1. ### display: flex :

- 부모 요소를 Flex 컨테이너로 설정하여 자식 요소들을 유연하게 배치한다

2. ### justify-content :

- 메인 축을 기준으로 자식 요소들 사이의 간격과 정렬을 조절한다

3. ### align-items :

- 교차 축을 기준으로 자식 요소들의 수직 정렬을 결정한다

---

## Grid 란?

행과 열을 동시에 제어하는 2차원 레이아웃 시스템이다

## 주요 속성:

1. ### display: grid :

- 부모 요소를 Grid 컨테이너로 설정하여 바둑판 모양의 설계를 가능하게 한다

2. ### grid-template-columns :

- 열(세로줄)의 개수와 너비를 설정합니다

3. ### grid-template-rows :

- 행(가로줄)의 개수와 높이를 설정합니다

## Flex vs Grid 차이점

### Flex (1차원)

- 기준: 한 번에 하나의 축(가로 또는 세로)만 다룹니다

- 특징: 요소의 크기가 불분명하거나 콘텐츠의 양에 따라 유동적으로 배치해야 할 때 유리하다

## Grid (2차원)

- 기준: 가로(행)와 세로(열)를 동시에 다룹니다

- 특징: 페이지 전체의 큰 구조를 잡거나, 요소들을 바둑판 형태로 정교하게 배치해야 할 때 유리하다

---

### flex-direction (정렬 방향)

부모 요소(Flex Container) 안에서 아이템들을 가로로 세울지, 세로로 세울지 결정하는 기준선(Main Axis)을 정합니다.

- `row (기본값)	왼쪽에서 오른쪽으로 (가로)	[ 1 ] [ 2 ] [ 3 ]`

- `column	위에서 아래로 (세로)`

- `row-reverse	오른쪽에서 왼쪽으로	[ 3 ] [ 2 ] [ 1 ]`

- `column-reverse	아래에서 위로`

---

### flex-wrap (줄 바꿈 여부)

아이템들이 부모의 너비를 초과했을 때, 한 줄에 억지로 구겨 넣을지 아니면 다음 줄로 넘길지를 정합니다

- `nowrap (기본값): 아이템 크기를 줄여서라도 무조건 한 줄에 배치합니다`

- `wrap: 공간이 부족하면 아이템을 다음 줄로 보냅니다`

- `wrap-reverse: 아래에서 위 방향으로 줄 바꿈을 합니다.`

---

### gap (간격 조정)

- `gap: 20px;: 가로, 세로 모든 아이템 사이에 20px의 간격을 줍니다.`

- `row-gap / column-gap: 특정 방향의 간격만 조절할 수도 있습니다.`
