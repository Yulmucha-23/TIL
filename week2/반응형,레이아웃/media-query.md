# 반응형(Media Query) 이란?

- ### 기기의 화면 크기, 해상도, 방향 등 특정 조건에 따라 다른 스타일(CSS)을 적용하는 기술이다

1. ### @media 이란?

- CSS 미디어 쿼리의 핵심 규칙으로, 화면 크기, 해상도 등 기기 특성에 따라 다른 스타일을 적용하여 웹 페이지의 반응형 디자인을 구현하는 데 사용됩니다

2. ### max-width 이란?

- CSS에서 요소가 가질 수 있는 최대 가로폭을 제한하는 속성이다

- 역할: 콘텐츠가 설정된 값보다 커지더라도 지정된 너비 이상으로 늘어나지 않게 잡아준다

3. ### min-width 이란?

- CSS에서 요소가 가질 수 있는 최소 가로폭을 지정하는 속성이다

- 역할: 화면이 아무리 작아지더라도 요소가 설정된 값보다 더 작게 줄어들지 않도록 보호한다

## 반응형 단위

1. #### % (퍼센트)

- 기준: 부모 요소의 너비 또는 높이
- 특징: 부모 크기에 연동되는 가변 레이아웃(너비) 설정 시 주로 사용

2. #### vw (Viewport Width)

- 기준: 브라우저 화면 너비의 1%
- 특징: 부모와 무관하게 오직 기기 화면의 가로 크기에만 반응하여 크기를 조절

3. #### vh (Viewport Height)

- 기준: 브라우저 화면 높이의 1%
- 특징: 스크롤 없이 화면 높이를 가득 채우는 섹션 구성 시 필수적으로 사용

4. #### rem (Root em)

- 기준: 최상위 요소(`<html>`)의 폰트 크기

- 특징: 브라우저 글꼴 설정에 유연하게 대응하며, 폰트 사이즈 단위로 가장 권장
