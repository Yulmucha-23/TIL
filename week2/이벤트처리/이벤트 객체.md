# 이벤트 객체 (Event Object) 이란?

- #### 클릭, 키보드 입력 등 DOM 요소에서 이벤트가 발생할 때 브라우저가 해당 이벤트 핸들러(함수)에 자동으로 전달하는 데이터 묶음이다

---

## 1. event

- #### 브라우저가 이벤트를 발생시킨 직후, 자동으로 생성하여 함수에 전달해 주는 정보 꾸러미이다

- 특징: 클릭한 좌표(x, y), 눌린 키보드 값, 발생한 시간 등 이벤트에 대한 모든 상세 데이터가 담겨 있습니다

## 2. event.target

- #### 이벤트가 발생한 실제 대상 요소(HTML 태그)를 가리킵니다

- 특징: 여러 개의 버튼이나 리스트 중 정확히 무엇이 클릭되었는지 판별할 때 필수적입니다

- 용도: 공통 부모에게 이벤트를 하나만 걸어두고, 자식 요소들을 구분해서 처리하는 이벤트 위임 방식에서 핵심적인 역할을 한다
