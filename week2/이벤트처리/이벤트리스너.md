# 이벤트 처리 (Event Handling 이란?

- #### 웹 페이지에서 발생하는 클릭, 키보드 입력, 마우스 오버 등의 동작을 감지하여 대응하는 기능이다

---

## 1. 이벤트 리스너 (addEventListener) 이란?

- #### 특정 요소에서 발생하는 사건(이벤트)을 기다리다가, 그 사건이 발생하면 지정된 함수를 실행시키는 도구입니다

- 구조: 대상요소 .addEventListener('이벤트종류', 실행할함수); 형태로 작성합니다

- 역할: HTML과 JavaScript를 분리하여 깔끔하게 관리할 수 있게 하며, 하나의 요소에 여러 개의 기능을 동시에 연결할 수 있다
