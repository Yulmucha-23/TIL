# 주요 이벤트 (Common Events)

## 1. click

- #### 마우스나 손가락으로 해당 요소를 클릭했을 때 발생한다

- 특징: 가장 빈번하게 사용되는 이벤트로, 버튼을 누르거나 링크를 클릭하여 페이지를 이동시키는 등 모든 선택 동작에 사용된다

## 2. input

- #### `<input>`이나 `<textarea>` 같은 입력창에 값이 타이핑될 때마다 발생한다

- 특징: 사용자가 글자를 입력하는 즉시 실시간으로 반응해야 할 때 매우 유용하다

## 3. change

- #### 요소의 값이 바뀌고 입력이 완료되었을 때(포커스를 잃거나 엔터를 칠 때) 발생합니다

- 특징: input과 달리 실시간이 아니라, 최종적으로 선택이 바뀌었을 때 주로 사용됩니다

---

### 마우스와 포인터 이벤트

- mouseenter / mouseleave: 마우스가 요소 위로 올라가거나 벗어날 때 발생합니다

- contextmenu: 마우스 오른쪽 버튼을 클릭했을 때 나타나는 메뉴 이벤트입니다

---

### 키보드 이벤트

단축키나 검색창 기능을 만들 때 필수

- keydown: 키를 누르는 순간 발생합니다
- keyup: 키에서 손을 뗄 때 발생합니다. 입력된 최종 값을 확인할 때 주로 씁니다

---

### 문서 및 윈도우 이벤트

브라우저 전체의 상태를 파악할 때 유용합니다

- DOMContentLoaded: HTML 문서 구조가 완전히 로드되었을 때 발생합니다
- resize: 브라우저 창의 크기가 바뀔 때 발생합니다. 반응형 요소를 자바스크립트로 제어할 때 핵심입니다.
- scroll: 페이지를 스크롤할 때 발생합니다
